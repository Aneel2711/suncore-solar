# SunCore Solar — Landing Page

A clean, modern, eco-themed landing page for a solar energy business built with HTML5, Tailwind CSS, and vanilla JavaScript. Designed with a single green-and-white color palette and subtle tree-canopy accents.

## Features

- **Green & White Tree-Accent Theme**: Clean emerald-green and white visual hierarchy with leaf-shaped badges and tree-canopy background accents.
- **Interactive Solar & Tree-Impact Calculator**: Dynamically estimates monthly savings, 25-year savings, recommended kW system size, and annual tree-equivalent CO₂ offset based on monthly electricity bill and roof sun exposure.
- **Custom SVG Artwork Included**: Lightweight, crisp SVG illustrations stored locally in `/images` so every visual loads offline with zero external image dependencies.
- **Responsive & Fast**: Mobile-first layout with smooth anchor navigation and instant quote form validation.

## Quick Start & GitHub Pages Deployment

1. Clone or upload all files in this folder to your GitHub repository.
2. Open `index.html` locally in any browser to preview immediately.
3. To host live for free on **GitHub Pages**:
   - Go to your repository **Settings → Pages**.
   - Under **Build and deployment**, select **Deploy from a branch**.
   - Choose the `main` branch and `/ (root)` folder, then click **Save**.
